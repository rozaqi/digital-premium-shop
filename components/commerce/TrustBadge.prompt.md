A single trust signal for the badge strip under the hero (Proses cepat, Garansi, etc.).

```jsx
<TrustBadge icon="zap" label="Proses cepat" tint="#5046E5" />
<TrustBadge icon="shield-check" label="Garansi produk" sublabel="Sesuai ketentuan" />
```

`icon` is a Lucide name. Use `layout="col"` for stacked grids. Requires `lucide.createIcons()`.
